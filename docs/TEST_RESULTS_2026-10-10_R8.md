## Ограничение

`PyJWT[crypto]` — необязательная зависимость, предназначенная только для проверки подписей. Базовое ядро работает без неё; тесты криптографии пропускаются при отсутствии набора `security`. Windows CI устанавливает зависимость перед тестами. DPAPI-сценарии на Windows выполняются только с синтетическими строками.
