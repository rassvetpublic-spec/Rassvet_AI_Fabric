# Windows-проверка Fabric: передача архива и возврат результата

**Статус:** запускатор v3 подготовлен, выполнение на компьютере владельца ещё не подтверждено. **ОС:** только Windows. **Язык:** русский.

## Рабочие пути

- Входные файлы помещаются в `D:\ЗАГРУЗКИ`: `RAiF-Windows-Source-0a41a338.zip` и `Start-RAiF-Windows-v3.ps1`.
- Рабочая область: `C:\GIT\Rassvet_AI_Fabric\.rai-fabric\windows-validation\runs\<идентификатор>`; используемая копия исходников изолирована.
- Итоговый ZIP создаётся непосредственно в корне проекта: `C:\GIT\Rassvet_AI_Fabric\RAiF-Windows-RESULT-*.zip`.
- Результат пользователь прикрепляет к чату без извлечения отдельных логов.

## Однострочный запуск

`powershell.exe -NoProfile -ExecutionPolicy Bypass -File "D:\ЗАГРУЗКИ\Start-RAiF-Windows-v3.ps1"`

Параметр `-ExecutionPolicy Bypass` относится только к данному процессу. Скрипт не изменяет глобальную политику и не обходит принудительные организационные ограничения.

## Предыдущие диагностические результаты

- v1: не выполнен на Windows PowerShell 5.1 из-за кодировки без BOM и некорректного разрешения Python.
- v2, архив `RAiF-Windows-RESULT-20261010_043528_2288de84.zip`: целостность 95/95 файлов подтверждена; результат сохранён в корне проекта; preflight и поиск Python заблокированы из-за WindowsApps alias и передачи аргумента `-3` прямо в интерпретатор. Модульные тесты не запускались.
- v3: скрипт сохранён с UTF-8 BOM, перебирает найденные кандидаты, включая `%LOCALAPPDATA%\Programs\Python\Python3*\python.exe`, проверяет каждого через `-c`, создаёт venv и только после этого запускает preflight из venv.

## Границы безопасности

1. Строгая SHA-256-проверка входного ZIP и всех его файлов перед запуском.
2. Исходные файлы не перезаписываются: рабочая копия отдельно от каталога с исходниками Git.
3. `Codex`, `Antigravity`, OAuth, подписные модели, персональные ключи и BPR40 не запускаются и не читаются.
4. Разрешены диагностика Windows/NVIDIA, синтетические Python-тесты и имитация `codex-mock`.
5. Допускается загрузка зависимостей Python с PyPI в отдельный `venv`. При необходимости сети можно запретить параметром `-NoDependencyDownload`, однако криптографические тесты тогда могут завершиться неполно.
6. Чекпойнт обратной передачи должен содержать реальный `verdict`, список выполненных шагов, ошибку и следующий курсор. PASS — только при подтверждённом полном цикле на пользовательской машине.
