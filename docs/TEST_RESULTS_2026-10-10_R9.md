# Протокол испытаний R9 — исправление упаковки 09.4

**Дата:** 10 октября 2026 года. **Курсор:** `RAI-FABRIC/09.4-WINDOWS_CI_RETRY`.

## Найденный сбой

После коммита `d3e308190ba86a979d61c72db4dd426069d5f5f2` GitHub Actions запуск №[38001746366](https://github.com/rassvetpublic-spec/Rassvet_AI_Fabric/actions/runs/38001746366) завершился ошибкой на Windows/Python 3.11 и 3.13. Оба задания остановились на установке дополнительного пакета `[security]`: поле `license` по ошибке располагалось внутри `[project.optional-dependencies]`. Это ошибка метаданных пакета; выполнение тестов на Windows не началось.

## Исправление

1. `license` перемещено в секцию `[project]`, как того требует pyproject/PEP 621.
2. Добавлены два теста проверки структуры TOML, чтобы не допустить повторного дефекта.
3. В изолированной Linux-среде создан wheel без внешних сетевых вызовов (`pip wheel --no-build-isolation --no-deps`).
4. **116 обнаруженных тестов, 113 исполненных, 3 Windows-зависимых пропущены, 0 ошибок.**

## Неопределённость

Окончательная приёмка Windows зависит от нового запуска GitHub Actions. Прототип DPAPI работает только с синтетическими тестовыми BLOB; реальных аккаунтов, локальных паролей, подписных токенов и BPR40 никто не касался.
