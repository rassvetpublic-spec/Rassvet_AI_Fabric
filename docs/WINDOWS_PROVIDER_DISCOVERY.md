# Диагностика установленных AI-приложений Windows — 09.7-B

**Назначение:** отдельная метаданных-only проверка локального Windows-компьютера перед рассмотрением официального подключения Codex App Server и иных поддерживаемых клиентов.

## Пакет поставки

- `RAiF-Windows-Discovery-09_7B.zip` — диагностический сканер + манифест SHA-256, без исходного кода доноров и без учётных данных.
- `Start-RAiF-Discovery-v4.ps1` — единственный внешний запускатор для Windows PowerShell 5.1, сохранённый в UTF-8 BOM.
- Папка загрузок: `D:\ЗАГРУЗКИ`.
- Рабочий корень: `C:\GIT\Rassvet_AI_Fabric`.
- Результат: `C:\GIT\Rassvet_AI_Fabric\RAiF-Windows-RESULT-DISCOVERY-*.zip`.

## Границы

Проверяются `Get-Command`, заранее перечисленные пути к исполняемым файлам, отфильтрованные метаданные Appx/Uninstall и диагностика `nvidia-smi`. Не производится чтение профилей авторизации, файлов `auth.json`, cookie, истории ChatGPT, исходников других проектов или содержимого процессов. Нет запуска Codex, Antigravity, Chrome, моделей, OAuth, платных API. Никаких изменений BPR40 и CONTROL TOWER.

Отсутствие команды в `PATH` **не доказывает отсутствие установленного приложения**. Если метаданные не дают достаточно данных, результат остаётся ограниченным, и дальнейшие действия согласуются отдельно.

Результирующий ZIP не публиковать в публичном GitHub: в нём могут встречаться метаданные локальных установок. Передавать только в закрытый чат.
