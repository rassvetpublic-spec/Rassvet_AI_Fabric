# CP-23 — межпроцессная защита реестра

Дата: 2026-10-10
Ветка: AG_pather

## Выполнено
1. Новый модуль `src/raif_ag_supervisor/filelock.py`: эксклюзивная блокировка записи при помощи `fcntl.flock` (Linux) / `msvcrt.locking` (Windows).
2. Блокировка освобождается операционной системой при закрытии файлового дескриптора или завершении процесса — не требует небезопасного удаления «зависшего» PID-файла.
3. `LocalAccountRegistry.recover()` и `import_manifest()` выполняются под одной блокировкой. Внутренний `_recover_locked()` предотвращает повторный захват блокировки при ошибке записи.
4. Попытка параллельной операции завершается отказом без обращения к данным аккаунтов.
5. `tests/test_filelock.py`: двойной захват, запрет восстановления при занятой блокировке.
6. Прежние тесты реестра дополнены проверкой нативного Windows vault, повреждённого журнала и некорректной версии JSON.

## Границы и риски
- Валидируются только синтетические данные; реальные refresh_token не использовались.
- Переключение аккаунтов в уже запущенном Antigravity Standalone не реализовано.
- Пока нет доказанной устойчивости к потере питания/порче файловой системы, к сетевым FS и проверке доверия к процессу, который вызывает Native Credential Manager.
- Поведение файловой блокировки на целевой машине RASSVET_DESKTOP не проверено: удалённое выполнение Desktop Commander ограничено квотой.
