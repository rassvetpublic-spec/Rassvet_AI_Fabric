## CP-22 — реестр account metadata
- `src/raif_ag_supervisor/registry.py` — собственная реализация реестра только из случайных непрозрачных ID.
- `accounts.json`: атомарное сохранение списка ID, без email, OAuth, cookie, путей и пользовательских запросов.
- `pending-import.json`: write-ahead журнал новых ID записывается ДО обращения в Credential Vault.
- При штатной ошибке откат; после аварийного прекращения явный `recover(vault)` удаляет незакоммиченные новые записи.
- Если реестр уже содержит все ID транзакции, восстановление НЕ удаляет их токены, а лишь очищает оставшийся журнал.
- Смешанное или повреждённое состояние трактуется как ошибка, требующая ручной проверки. Реестр отклоняет пустой журнал и нестрогие версии схемы.
- `tests/test_registry.py`: синтетические тесты, в том числе имитация прерывания, откат, атомарная граница commit, коллизии, недопустимые схемы и Windows Credential Manager smoke test.
- Исходный пользовательский файл аккаунтов НЕ читался, токены/email в GitHub НЕ передавались.

## Ограничения
1. Прототип single-writer. Межпроцессная блокировка ещё отсутствует.
2. Атомарная замена файла не является полной гарантией сохранности при потере питания; тесты power-loss не выполнялись.
3. Linux/Windows CI для текущих коммитов НЕ запускался ради экономии лимитов. Тестовый код требует подтверждения.
4. Нет управления живой сессией Antigravity Standalone и нет доказанного hot swap.
