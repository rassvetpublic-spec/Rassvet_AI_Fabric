## 2. Стандарт вывода BPR5 R3.3 (Смысл первичен — работа внутри — горизонт ABC×XYZ)

- **Язык общения:** Русский (`RU`). Термины: `русский термин (English term)`.
- **Блок 1 — Триада смысла с подтверждением делом внутри (Zero Duplication):**
  Ответ начинается сразу с триады без отдельной дублирующей шапки «Результат»:
  - **🎯 Для чего и что сделано (what_for + proof):** 1–2 предложения цели шага, а внутри — краткий список сделанного (файлы, коммиты, PID/порты, тесты) как подтверждение. Запрещено дублировать список ниже в отдельных главах.
  - **💎 Зачем (why_benefit):** практическая польза простым языком.
  - **⏱️ Почему сейчас (why_now):** предпосылка или триггер текущего момента.
- **Блок 2 — Компактная панель чекпойнта, метрик и CKS:**
  - Курсор общего плана (`Phase 0..N`) в 1 строку (детальный план — только для будущих задач).
  - Единая компактная таблица: `SHA` / Ветка · Живые сервисы · Метрики `SLO` vs `Факт` · Гейты `G0–G4`.
  - **Свернутый аудит CKS при `6/6 PASS`:** строго 1 строкой: `🛡️ Аудит CKS (6/6 PASS): bias · leakage · confusion · complexity · alternatives · ssot — отклонений нет` (раскрывается только при `WARN`/`FAIL`/`UNKNOWN`).
- **Блок 3 — 🔭 Горизонт дальнейших шагов с ABC×XYZ анализом:**
  - Индекс `[Класс A/B/C - X/Y/Z]`, суть шага простым языком, «Что даст сразу» и «Цена откладывания».
  - **Обязательная опция:** `[Класс A - X] Выполнить всё по очереди + зарегистрировать MTD для этого шага` (при ответе «да»/«всё» агент исполняет весь перечень).
  - **Инвариант сохранности предложений (No Dropped Proposals):** отложенные предложения не теряются, а фиксируются в Issue бэклога через метрику `CKS#457` / `\\.\pipe\fleet_metrics`.
- **Безусловная видимость:** маркеры `[ERROR]`, `[BLOCKER]`, `[MATERIAL_UNKNOWN]`, `[REQUIRED_USER_ACTION]` никогда не скрываются. Внутренний chain-of-thought в служебный текст ответа не выводится.

## 3. Ключевые инварианты флота

1. **Gate Владельца (Merge Invariant):**
   **Никогда не делать merge в ветку `main` без прямой команды владельца: `mtd`, `MTD` или `мтд`.**
2. **Безопасность данных (Safe Sync Gate):**
   `PRIVACY > SECURITY > DATA_INTEGRITY > KNOWLEDGE > AUTO-SYNC`. При любой ошибке — немедленный STOP.
3. **Методологические инварианты:**
   - Роли: `HARVESTER` (сбор фактов) -> `DESTROYER` (стресс-тесты/фальсификация) -> `SEALER` (запечатывание/паспорта).
   - Эпистемическая честность: `UNKNOWN != PASS`.
   - LIFO-стек возврата ветвлений: `RETURN_TO: main_goal`.
4. **Трёхуровневая матрица владения навыками (`SKILL_OWNERSHIP_MATRIX`):**
   Слой 1 (Git Repositories `.agents/skills/` SSOT) -> Слой 2 (User Plugins) -> Слой 3 (Platform Builtin). Нулевое дублирование между слоями (`ZERO_DUPLICATE_IN_PLUGINS`).
5. **Паспортизация и метрики:**
   Любое изменение кода включает Sidecar-паспорт `<module>.passport.json` (`BPR40_SIDECAR_PASSPORT/1.1`) для защиты от дрейфа (`CONTRACT_DRIFT`) и доставку метрик (`\\.\pipe\fleet_metrics`).
