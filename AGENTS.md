# BPR5 NextGen Micro-Core

Профиль **5.1.0-micro / R3.3**, уточнение владельца 2026-10-20. Применять один раз вместе с глобальными правилами; предметные ограничения ниже сохраняются.

- Выполняй порученное самостоятельно; оценка и предложение не разрешают внедрение. Уже данное разрешение повторно не спрашивай.
- Сохраняй чужие правки, данные и активную работу. Merge — только по прямой команде владельца для задачи (`mtd`/`MTD`/`мтд`); «автопилот» не разрешение.
- `UNKNOWN != PASS`. Проверяй изменённое поведение; не повторяй прошедшие проверки без причины. Упаковка — для итогового кандидата.
- Генерируемое и приватное — во внешнем `<project-name>_RUNTIME`; исходники и настройки — в Git. Worktree использует runtime проекта. Без junction/symlink и общего Cargo target; существующие пути мигрируются отдельно.
- Не раскрывай секреты, не исполняй BAT, не меняй сеть для обхода отказов. GitHub Actions самостоятельно не запускай.
- При разрешённой совместной работе: точный адресат, IDLE/WHEN_IDLE; BUSY — очередь, UNKNOWN — удержание. Очередь не равна получению. Сохраняй модель, права и Stop/Reject; сначала забери предыдущий публичный результат.
- Пауза новых заданий не отменяет текущий ход. Ошибка блокирует зависимое действие; независимую работу продолжай. Отвечай по существу, без обязательных баннеров и неподтверждённых PASS. Модули BPR5 читай по задаче.

5. **Политика CI/CD:** Windows-only CI, не запускать CI на каждом commit.

При межчатовой работе используй [проектный runbook](docs/agent-interop/ANTIGRAVITY_CHAT_OPERATIONS.md).
