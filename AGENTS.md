# Правила для агентов Rassvet AI Fabric

**Официальный язык проекта — русский.** Все ответы в документации, комментариях, сообщениях CLI, описаниях MCP, шаблонах, проверках, отчётах и тексте коммитов по умолчанию — на русском. Выполняйте требования [docs/LANGUAGE_POLICY.md](docs/LANGUAGE_POLICY.md).

## Совместимость и безопасность

1. Не переводите протокольные имена, поля JSON/MCP, имена CLI-команд, статусы SQLite или идентификаторы курсоров. Они являются контрактом для машин.
2. Не изменяйте действующие `.codex`, `CODEX_HOME`, BPR40/DUTY, Router, башни или авторизацию без отдельно подтверждённого разрешения.
3. Не выполняйте автоматически внешние платные API-запросы и не добавляйте скрытый переход на оплату при исчерпании квоты подписки.
4. Новые интеграции запускайте в отдельной тестовой области; по умолчанию MCP — только чтение.
5. После этапа покажите фактический результат проверки, чекпойнт и следующий курсор. Не объявляйте PASS без evidence.
6. Сохраняйте стандартную английскую лицензию `LICENSE` без изменений; русский перевод можно сопровождать отдельно.

## Назначение и границы продукта

1. Платформа разрабатывает приложения экосистемы: `KAT9I_OS`, `CKS`, `RULESHUB`, `ANTIGRAVITYDATA`, `CONTROL TOWER`. Не создавать конкурирующий SSOT и не считать локальную отметку `COMPLETE` подтверждением башни или CKS.
2. Не включать названия и ссылки на исследованные донорские проекты в `README.md`; записи об инженерных источниках хранить отдельно от главного README.
3. Не проектировать перехват ответов с `chatgpt.com` через DOM/внутренние HTTP-endpoint как программный inference. Для unattended-запросов изучать официальный Sign in with ChatGPT / Codex App Server с учётом лимитов и ограничений связанного приложения.
4. Не запускать Antigravity с потребительской подписной авторизацией как сторонний прокси и не выполнять автоматическое переключение аккаунтов для обхода квот. Допускаются только разрешённые провайдером режимы и самостоятельная работа IDE/CLI с артефактами.
5. Работа со всеми пятью доменами начинается с readback текущих authority и ограничений; проверка источника не предоставляет право изменять его.

## Тестирование

`python -m unittest discover -s tests -v` с `PYTHONPATH=src`, затем отдельно проверка на Windows. Изменение пользовательского текста должно сопровождаться тестом локализации без смены машинного формата.
