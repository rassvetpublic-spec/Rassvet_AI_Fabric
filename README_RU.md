# Rassvet AI Fabric 0.1.0 — независимый прототип

**Создано с нуля.** Репозитории [oh-my-codex](https://github.com/Yeachan-Heo/oh-my-codex) и [Superpowers](https://github.com/obra/superpowers) изучены как доноры архитектурных идей, их исходники не переносились. Предыдущий `omx-app` также не использован как база кода.

## Что реально работает

1. Локальная SQLite-очередь с зависимостями задач, атомарной выдачей lease, heartbeat, поколениями lease и защитой от одновременного захвата.
2. Чекпойнты `{stage, verdict, cursor, evidence, sha256}` после ключевых переходов; проверка SHA-256 при чтении.
3. Обработка оборванных запусков без слепого повторения внешних действий: статус BLOCKED и курсор `VERIFY_EXTERNAL_SIDE_EFFECTS`.
4. Минимальный MCP-server по stdio с восьмью инструментами **только для чтения**. Есть ограничение рабочего каталога, отказ при symlink/junction и блокировка типичных секретов.
5. Имитатор исполнения `mock`, которому не нужны аккаунт, интернет или GPU.
6. Опциональный адаптер Antigravity CLI `agy` для headless-запуска с явным разрешением, но **его реальное исполнение на Windows ещё не подтверждено**.
7. PS1-сценарии теста и демонстрации. Вызов `demo.ps1` работает в отдельном `%TEMP%`.

## Чего пока нет

- Реального управления Codex через App Server, регистрации/обновления OAuth и подписных inference-вызовов.
- Подключения локальной LLM на RTX 5070 Ti: только диагностический `nvidia-smi`.
- Взаимодействия с Chrome/ChatGPT Web.
- Фонового Windows Service, гарантированного restart после reboot и обработки всего дерева процессов.
- Записи в BPR40 / DUTY / три башни. Новый проект **не имеет полномочий** менять их.
- Доступа к удалённым пользователям: MCP без сетевого входящего порта и без удалённой авторизации.

## Проверка через PowerShell

Распаковать архив отдельно от `C:\CODEX`, `.codex`, `C:\GIT\BPR40` и действующих пользовательских профилей. В каталоге проекта открыть PowerShell:

1. Запустить `./scripts/run-tests.ps1`.
2. Запустить `./scripts/demo.ps1`.
3. Посмотреть напечатанный путь в `%TEMP%`, где создана тестовая SQLite-БД.

Если политика выполнения PS1 запрещает скрипты, нужно разрешение для текущего процесса в соответствии с локальной политикой безопасности. **Не требуется изменять `CODEX_HOME`, профили, `AGENTS.md` или реестр.**

Для работы с произвольным тестовым репозиторием CLI всегда требует явного `--db`, а инструмент MCP требует ещё явного `--workspace`. Подписные модели не вызываются автоматически. Перед попыткой Antigravity нужно предварительно проверить авторизацию `agy`, политику лимитов и разрешить внешний запуск через `--allow-external`.

## Архитектура первой версии

`BPR40 external → RAI core → task journal/checkpoints → MCP read-only / local CLI / opt-in worker`. Рабочие пространства Codex и Antigravity являются отдельными клиентами и исполнителями в будущих версиях, не источником BPR40 authority.

**Технический предел:** SHA-256 защищает от случайного повреждения чекпойнтов, а не от злонамеренной перезаписи БД. Полноценная BPR40 публикация и криптографические receipts требуют следующего отдельного этапа.

Актуальные детали и дорожная карта на английском находятся в `README.md`, `docs/ARCHITECTURE.md` и `docs/ROADMAP.md`.
