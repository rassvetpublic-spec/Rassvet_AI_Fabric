# Скилл сбора предложений сессии (/all-proposals)

Этот скилл предназначен для извлечения, классификации и консолидации всех предложений, гипотез и развилок, озвученных агентом или пользователем в текущем диалоге.

## Алгоритм работы

1. **Анализ истории сессии (Transcript Scan):**
   - Просканировать стенограмму текущей сессии от первого сообщения до текущего момента.
   - Извлечь все карточки горизонта решений `[Класс A/B/C - X/Y/Z]`, предложения по архитектуре, оптимизации, рефакторингу и скриптам.

2. **Классификация по матрице ABC×XYZ:**
   - **Класс ценности:**
     - `Класс A`: Критическая польза для ядра, безопасности, целостности или снижения системного оверхеда.
     - `Класс B`: Улучшения эргономики, локальные ускорения, вспомогательные утилиты.
     - `Класс C`: Косметические правки, идеи на перспективу, бэклог.
   - **Класс неопределённости:**
     - `X`: Детерминированное, предсказуемое исполнение (0 неизвестных).
     - `Y`: Умеренная неопределённость (требует проверки зависимостей).
     - `Z`: Высокая неопределённость / исследование (Research & Spike).

3. **Формирование сводной таблицы:**
   - Номер (№)
   - Индекс класса `[Класс ... - ...]`
   - Содержание предложения простым языком
   - Текущий статус: `ВЫПОЛНЕНО`, `В РАБОТЕ`, `ОТКЛОНЕНО`, `ПОГЛОЩЕНО`, `В БЭКЛОГЕ`
   - Практический результат / Примечание

4. **Инвариант сохранности (No Dropped Proposals):**
   - Если есть невыполненные предложения класса A или B, которые не берутся в работу, предложить пользователю перенести их в Issue проекта или зафиксировать в бэклоге.
